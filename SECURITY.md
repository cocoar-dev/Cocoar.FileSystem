# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.x.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please email bwi@cocoar.dev instead of opening a public issue.

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will respond within 48 hours and work with you to address the issue.

## Security Best Practices

When using Cocoar.FileSystem:
- Validate and sanitize file paths before monitoring
- Be careful when monitoring paths that users can influence
- Use appropriate permissions for monitored directories
- Consider the security implications of automatic file processing

Thank you for helping keep Cocoar.FileSystem secure!
